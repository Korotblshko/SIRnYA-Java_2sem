# OTP Service

Backend-сервис для генерации и проверки OTP-кодов с авторизацией по JWT, хранением данных в PostgreSQL и разделением прав на пользователя и администратора.

## Возможности

- Регистрация пользователей.
- Логин и получение JWT-токена.
- Генерация OTP-кода для операции.
- Проверка OTP-кода.
- Просмотр списка пользователей для администратора.
- Удаление пользователя администратором.
- Сохранение сгенерированного OTP-кода в файл.
- Автоматическое помечение просроченных OTP-кодов как "EXPIRED".

## Стек

- Java 21
- Maven
- PostgreSQL 17
- JDBC
- com.sun.net.httpserver
- JJWT
- BCrypt
- SLF4J + Logback

## Структура проекта

- `com.otp.Api` — HTTP-обработчики.
- `com.otp.Service` — бизнес-логика.
- `com.otp.Dao` — работа с базой данных.
- `com.otp.Model` — модели данных.
- `com.otp.Util` — вспомогательные классы.

## Требования

- Java 21
- Maven
- PostgreSQL 17
- База данных `otp_service`
- Порт PostgreSQL: `5433`
- Порт приложения: `8080`

## Настройка базы данных

Перед запуском создайте БД `otp_service` и выполните SQL-скрипт создания таблиц:

- `users`
- `otp_config`
- `otp_codes`

После этого проверьте, что в таблице `otp_config` есть одна запись.

## Запуск проекта

1. Откройте проект в IntelliJ IDEA.
2. Убедитесь, что PostgreSQL запущен на порту `5433`.
3. Убедитесь, что в `DatabaseConnection.java` указаны корректные параметры подключения.
4. Запустите класс `com.otp.Main`.

Сервер будет доступен по адресу:

`http://localhost:8080`

## API

### 1. Регистрация пользователя

**POST** `/register`


### 2. Логин

**POST** `/login`


### 3. Генерация OTP

**POST** `/otp/generate`


### 4. Проверка OTP

**POST** `/otp/validate`


### 5. Список пользователей администратора

**GET** `/admin/users`


## Файл с OTP

После генерации кодов они сохраняются в:

`output/otp.txt`

## Что реализовано частично

В проекте подготовлены точки расширения для:
- отправки кода по Email,
- отправки кода через SMS,
- отправки кода через Telegram.
